# 読者と対象範囲

## 想定読者

| 読者 | 主な用途 |
| --- | --- |
| app-team | アプリのデプロイ、設定、制約確認 |
| sre-team | 障害対応、運用改善、レビュー |
| platform-team | 仕様管理、変更周知、サポート |
| security-team | セキュリティ制約と例外レビュー |

## このサイトが扱うもの

- Kubernetesプラットフォームの環境構成
- プラットフォーム独自仕様
- アプリチーム向け作業手順
- 提供API、CRD、CLI、CIテンプレート
- アプリ側の準拠チェックリスト
- 代表的な障害切り分け

## このサイトが扱わないもの

- 個別アプリケーションの詳細仕様
- Kubernetes一般論の網羅的な説明
- クラウドアカウント管理の手順
